# Проект drf_learning

## Описание:

Проект course_drf_habits - это бэкенд-часть SPA веб-приложения для приобретения новых полезных привычек 
и искоренению старых плохих привычек.

## Стек используемых технологий (библиотек):
+ Python 3.12.10
+ poetry
+ django 6.0.8
+ djangorestframework 3.18.0
+ dotenv 0.9.9
+ gevent 26.8.0
+ pillow 12.3.0
+ psycopg2 2.9.12
+ python-dotenv 1.2.3
+ redis 8.1.0
+ requests 2.34.2
+ ipython 9.16.1
+ drf-yasg 1.21.15
+ stripe 15.5.0
Все контроллеры имеют способ определения и обработки представлений в DRF с помощью классов(метод CBV).

## Установка:

1. Клонируйте репозиторий:
    ```
     https://github.com/ViktorPilot/course_drf-habits.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Создайте и заполните файл `.env`.
8. Программа готова к работе.

## Настройка приложения:

1. Для запуска локального сервера у себя на компьютере необходимо в терминале ввести команду:
`python manage.py runserver 8000`(для Windows), `python3 manage.py runserver 8000`(для Unix-систем), 
где крайним значением указан порт запускаемого сервера.
2. Создайте миграции командой `python manage.py makemigrations`.
3. Примените миграции командой `python manage.py migrate`.

## Порядок работы с `myhabits` и `users`:

1. Реализована возможность создания, просмотра, редактирования и удаления привычек пользователя, используя 
API-запросы на локальный сервер.
2. Реализована возможность просмотра всех публичных привычек пользователей, используя 
API-запросы на локальный сервер.
3. Реализована возможность редактирования пользователей, используя API-запросы на локальный сервер.
4. Реализована возможность создания, просмотра, редактирования и удаления пользователя, используя 
API-запросы на локальный сервер.
5. Реализована возможность регистрации пользователей и получения ими токена для авторизации в приложении.
6. Реализованы валидаторы для текущей привычки:
   + исключающие одновременный выбор связанной привычки и указания вознаграждения.
   + по времени выполнения, которое должно быть не больше 120 секунд.
   + по возможности добавлятьк только привычки с признаком приятной привычки.
   + по ограничению добавления к приятной привычки вознаграждения или связанной привычки.
   + по выполнению привычку реже, чем 1 раз в 7 дней.
7. Реализована пагинация списка привычек с выводом по 5 привычек на страницу.
8. Реализованы эндпоинты: регистрация, авторизация, вывод списка привычек текущего пользователя с пагинацией, 
вывод списка публичных привычек, создание привычки, редактирование привычки, удаление привычки.
9. Реализована интеграция сервиса с мессенджером Телеграм, который будет заниматься рассылкой уведомлений.
10. Настроен CORS для подключения к проекту на развернутом сервере.
11. Настроен вывод документации. Каждый эндпоинт описан с использованием drf-yasg.

## Тестирование:

Данный проект покрыт юнит-тестами с использованием фреймворка rest_framework.test.
Для их запуска выполните команду `python manage.py test` из корневой директории проекта.

### Реализованы:

+ Тестирование корректности работы CRUD привычек.
+ Тестирование корректности работы CRUD пользователя.
+ Тестирование валидатора времени на выполнения привычки.
+ Тестирование валидатора периодичности выполнения привычки.
